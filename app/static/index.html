GET /patients

List all registered patients with optional query filters (?last_name=, ?phone_number=, ?date_of_birth=). Automatically excludes soft-deleted records.

Sample cURL
curl -X GET "http://localhost:8000/patients" \
  -H "Accept: application/json"
POST /patients

Create a new patient record with strict server-side validation. Enforces all demographic field rules and returns 201 Created with UUID.

Sample Payload
{
  "first_name": "Marcus",
  "last_name": "Vance",
  "date_of_birth": "1988-08-24",
  "sex": "Male",
  "phone_number": "5125550188",
  "address_line_1": "742 Evergreen Terrace",
  "city": "Austin",
  "state": "TX",
  "zip_code": "78704"
}
PUT /patients/{id}

Partial update of patient demographic fields. Only specified fields are updated and re-validated.

Sample cURL
curl -X PUT "http://localhost:8000/patients/{id}" \
  -H "Content-Type: application/json" \
  -d '{"address_line_1": "500 South Congress Ave"}'
DELETE /patients/{id}

Soft-delete patient record (sets deleted_at timestamp). Record is preserved in database but excluded from active queries.

Sample cURL
curl -X DELETE "http://localhost:8000/patients/{id}"
POST /api/voice/webhook

Vapi Voice AI webhook gateway. Handles assistant-request (returns Sarah prompt + tools), function-call (dispatches lookup_patient, register_patient, update_patient), and end-of-call-report (persists transcript).

Vapi Function Call Tool Spec
{
  "message": {
    "type": "function-call",
    "functionCall": {
      "name": "lookup_patient",
      "parameters": { "phone_number": "5125550188" }
    }
  }
}
